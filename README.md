## Project 2: Stolen Dance

#### by Sofia Garcia- Ortiz
October 14, 2024


## Overview
Displayed is the first verse of "Stolen Dance" by Milky Chance which is an Indie Pop song that came out in 2014. By animating certain words and ideas that are discussed in the song, the viewer gets a lense into how I define my community. Simply hover over certain words that stand out from the others to be transported to the next line of the song until the verse is over.

## Technical Overview
As words pop up, play around with the hover feature on each page to see if any words have hidden movements that need to be signaled. When you're done exploring with the hover feature, click on the word that stands out the most, it will be obvious, to direct you to the next page.
